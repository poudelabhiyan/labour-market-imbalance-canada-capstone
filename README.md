# AI-Driven Labour Market Imbalance Analysis — Canada

This repository contains the capstone project for DAMO 699 (Master of Data Analytics, University of Niagara Falls Canada).

The project analyzes labour market imbalance in Canada using Statistics Canada data (2015–2024). Labour market imbalance is measured using the vacancy-to-unemployment ratio and examined through descriptive, diagnostic, predictive, and scenario-based analysis.

The objective is to support evidence-based workforce planning through forecasting and scenario evaluation.

## Project Structure
Each folder represents a formal phase of the analytics lifecycle, aligned with the approved project proposal and course requirements.
